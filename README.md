# Student Performance Analysis

A student performance analysis project using **Python, Pandas, Excel, and Power BI** to analyze student data and identify performance trends.

## Project Overview

This project analyzes student academic data to understand performance patterns and key factors affecting student results.

## Tools & Technologies

* Python
* Pandas
* Excel
* Power BI

## Key Analysis

* Student performance analysis
* Attendance analysis
* Academic score analysis
* Department-wise performance
* Performance trends and insights
* Power BI dashboard visualization

## Dataset

The project uses student data containing information such as:

* Student ID
* Gender
* Age
* Department
* Attendance
* Midterm Score
* Final Score
* Assignments
* Quizzes
* Participation
* Projects
* Grade
* Study Hours
* Parent Education Level

## Project Files

* `StudentData.csv` – Student dataset
* `README.md` – Project documentation

## Objective

The objective of this project is to analyze student data and create meaningful insights using data analysis and visualization tools.
